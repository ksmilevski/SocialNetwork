# SocialNetwork – JavaScript-Powered Social Media Simulator 🌐

**SocialNetwork** is a lightweight, web-based social media platform built entirely with vanilla JavaScript, HTML, CSS, and Bootstrap. Designed primarily for learning and training purposes, the project helps developers understand core web development concepts such as user authentication, session handling, DOM manipulation, and data interaction using MockAPI.

## 🎯 Purpose
This project serves as a practical introduction to:
- JavaScript-based user interactions
- Frontend session management
- CRUD operations using RESTful API services (MockAPI)
- UI building with Bootstrap

## 🌟 Key Features

### 👥 User Features
- **Authentication System:** Users can register and log in using intuitive, form-based authentication.
- **Session Management:** Sessions are handled via cookies; authenticated users are redirected to the homepage, while guests are sent to the login page.
- **Profile Management:** Logged-in users can update their personal profile information or delete their account entirely.

### 📝 Post Management
- **Create Posts:** Users can share text-based posts.
- **View Feed:** A live feed displays all shared posts in chronological order.
- **Like System:** Each post includes a like button and counter to simulate engagement.

## 🛠️ Technologies Used
- **Frontend:** JavaScript, HTML, CSS, Bootstrap  
- **Data Management:** [MockAPI](https://mockapi.io) for simulating RESTful backend services

## 🚀 Learning Outcomes
- Practice JavaScript DOM manipulation and event handling
- Understand the flow of a typical web app (login → session → data interaction)
- Work with external APIs to perform CRUD operations
- Build responsive UIs using Bootstrap
